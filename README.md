# 슬기로운 직장생활 (Android)

갤럭시 2020년 이후 기종(Android 10 / API 29 이상) · Kotlin + Jetpack Compose

## APK 받는 법 (GitHub Actions)
1. GitHub에 새 저장소(예: `worklife-app`)를 만들고 이 폴더 전체를 올립니다.
2. Actions 탭 → **Build APK** 가 자동 실행 (단위 테스트 → APK 빌드, Gradle 캐시 사용)
3. 완료된 실행 → Artifacts → `worklife-apk` 다운로드 → 폰에서 설치
   - 서명키(`app/worklife.jks`)가 고정이라 **새 버전을 덮어 설치해도 기록이 유지**됩니다.

## 처음 설정 (폰에서)
1. 설정 > 권한 점검: 정확한 위치 → '항상 허용' → 알림 → 정확한 알람 → 배터리 '제한 없음'
2. 설정 > 회사: 이름 입력, 회사에서 **[지금 위치를 회사로]** → 저장
3. 갤럭시: 설정 > 배터리 > 백그라운드 사용 제한 > **절전 예외 앱**에 추가

## 퇴근 감지 구조 (한 경로가 막혀도 다른 경로로)
| 순서 | 경로 | 역할 |
|---|---|---|
| 1 | 정확한 알람 (정시 5분 전) | 위치 서비스 시작 |
| 2 | 포그라운드 위치 서비스 (1분 간격, 구글 위치 + 기기 GPS 동시) | 주 판정 |
| 3 | 지오펜스 (OS가 출입 이벤트 전달) | 서비스가 못 떠도 이탈 감지 → 서비스 재시작 |
| 4 | 앱 열 때 / 매일 00:10 마감 | 남은 날 자동 정리 |
| 5 | 기록 없음 → 정시 처리, 애매함 → '확인필요' 알림 | 마지막 안전망 |

## 폴더
- `core/` 계산·판정 로직 (안드로이드 무관, JUnit 33개)
- `data/` SQLite + 설정 · `bg/` 서비스·알람·지오펜스 · `ui/` 화면 4개 (홈/근무기록/급여/설정)
